# catalagomdos

Proyecto reiniciado desde cero. Este repositorio contiene el código base del catálogo de productos. En este punto el proyecto está limpio: no hay productos en la base de datos y el script de auto‑seed ha sido eliminado.

Próximos pasos:

- Deploy en Vercel.
